# Smart House Backup

Smart House Backup is a personal, non-commercial backup solution for a privately operated Raspberry Pi smart home system.

The application uses Google Drive through rclone to store encrypted backup archives, allowing the owner to recover important application configurations and data after hardware failure.

## How it works

- Creates backup archives locally on the owner's Raspberry Pi.
- Encrypts backup contents before uploading them to Google Drive.
- Uses Google Drive access only to manage backup files.
- Does not provide public access to smart home devices or their data.
- Does not sell or share user information with third parties.

This application is intended for personal use by its owner.
